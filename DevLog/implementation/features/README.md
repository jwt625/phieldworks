# Feature logs

Deeper contracts for shipped prototype subsystems. Each is a mix of design
decisions, implementation notes, validation and an explicit open/TBD list.

| Doc | Subsystem |
| --- | --- |
| [005 — Ports, routing and presentation](005-ports-routing-and-presentation.md) | Simulation/presentation split, typed ports, grid routes, material packets, power grid, diagnostics, route editing. Holds the open decisions/TBD list (paid segments, splitters, poles, multi-source bus, bend calibration). |
| [006 — World interaction and onboarding](006-world-interaction-and-onboarding.md) | Direct camera, terrain and dedicated orientation art, categorized build palette, contextual tutorial, ecology/investigation, defense gate, human playtest checklist |

These describe prototype behavior and its limits, not future plans. Pair with the
matching `planning/` tranche before extending a subsystem.
